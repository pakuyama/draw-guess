## 막힌 점 / 질문

- [나가기]는 지금 첫 화면으로 돌아가기만 한다. 서버 목록에서 빼고 방장을 넘기는 처리는 T21에서 한다.
- [게임 시작] 버튼은 화면에만 있고, 서버 처리는 T12에서 연결한다.
- 출제자는 T12(게임 시작)에서 정해지므로, 같이 그리기는 지금 자동 테스트에서만 확인할 수 있다. T12 이후 연습 페이지나 게임 화면에서 직접 확인 가능.
- 이미 가상환경을 만든 경우 `pip install -r requirements.txt`를 한 번 더 실행해야 WebSocket이 켜진다.
