- T24 지인 플레이 테스트는 사람이 직접 해야 한다. 진행 방법·질문지는 `docs/playtest.md`.

- 이미 가상환경을 만든 경우 `pip install -r requirements.txt`를 한 번 더 실행해야 WebSocket이 켜진다.
