# 화면 와이어프레임

`design.md` 7장(화면 구성)을 그림으로 옮긴 것입니다. 네 화면은 `templates/index.html` 한 페이지 안에서 전환합니다.
`[ ]`는 버튼, `( )`는 입력칸, `★`는 방장, `✏`는 출제자, `✔`는 이번 턴에 맞힌 사람입니다.

## 1. 메인 화면

닉네임을 정하고 방을 만들거나 참가합니다. (R1, R2)

```text
┌──────────────────────────────────────────────┐
│                                              │
│                 🎨 그려봐!                    │
│        친구와 함께 그리고 맞히는 게임          │
│                                              │
│        닉네임  ( 최대 10글자          )        │
│        아바타  ◀  🐱  ▶                       │
│                                              │
│            [      방 만들기      ]            │
│                                              │
│        ───────────  또는  ───────────         │
│                                              │
│        방 코드 ( ABC123 )  [ 참가 ]            │
│                                              │
│        ⚠ 없는 방 코드예요.   ← 오류 시 표시      │
└──────────────────────────────────────────────┘
```

- 초대 링크(`/?room=ABC123`)로 들어오면 방 코드 칸이 미리 채워집니다.
- 닉네임이 비어 있으면 버튼이 눌리지 않습니다.
- 오류 메시지: "없는 방 코드예요.", "방이 가득 찼어요. (8/8)", "이미 게임이 진행 중이에요."

## 2. 대기실

사람을 모으고 방장이 게임을 시작합니다. (R2, R9)

```text
┌──────────────────────────────────────────────┐
│ 그려봐!                          [ 나가기 ]    │
├──────────────────────────────────────────────┤
│  방 코드  ABC123   [ 코드 복사 ] [ 링크 복사 ]   │
├──────────────────────────────────────────────┤
│  참가자 (4/8)                                 │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐       │
│  │ 🐱 윤하 ★ │ │ 🐶 민수   │ │ 🐰 지영   │       │
│  └──────────┘ └──────────┘ └──────────┘       │
│  ┌──────────┐ ┌ ─ ─ ─ ─ ┐ ┌ ─ ─ ─ ─ ┐         │
│  │ 🐻 현우   │   빈 자리     빈 자리            │
│  └──────────┘ └ ─ ─ ─ ─ ┘ └ ─ ─ ─ ─ ┘         │
├──────────────────────────────────────────────┤
│  게임 설정: 3라운드 · 80초 (MVP는 고정)          │
│                                              │
│            [     게임 시작     ]   ← 방장만     │
│        2명 이상 모이면 시작할 수 있어요            │
└──────────────────────────────────────────────┘
```

- 방장이 아닌 사람에게는 [게임 시작] 대신 "방장이 시작하기를 기다리는 중…"이 보입니다.
- 방장이 나가면 다음 사람에게 ★가 넘어갑니다.

## 3. 게임 화면 (PC)

```text
┌──────────────────────────────────────────────────────────────────┐
│  라운드 1/3        힌트:  ㄱ _ _   (3글자)           ⏱ 52초         │
├────────────┬─────────────────────────────────────┬───────────────┤
│ 점수판      │                                     │ 채팅           │
│            │                                     │               │
│ 1 🐱 윤하 ✏ │                                     │ 민수: 강아지?   │
│      120   │                                     │ 지영: 늑대      │
│ 2 🐶 민수 ✔ │            (  캔 버 스  )             │ ✅ 현우님이     │
│      95    │                                     │   정답을 맞혔어요│
│ 3 🐻 현우 ✔ │                                     │               │
│      80    │                                     │               │
│ 4 🐰 지영   │                                     │               │
│      40    │                                     │ ( 정답 입력 )  │
├────────────┴─────────────────────────────────────┴───────────────┤
│  ● ● ● ● ● ● ● ●   │  ━ ━━ ━━━  │  [지우개] [되돌리기] [전체 지우기]  │
│  (색 8가지)          (굵기 3단계)    ← 출제자에게만 보임                 │
└──────────────────────────────────────────────────────────────────┘
```

**턴 시작 — 출제자 화면에만 뜨는 창** (10초 안에 안 고르면 자동 선택)

```text
        ┌──────────────────────────────────┐
        │    그릴 제시어를 골라 주세요 (8초)   │
        │                                  │
        │   [ 고양이 ]  [ 등대 ]  [ 열기구 ]   │
        └──────────────────────────────────┘
```

**다른 사람 화면:** "✏ 윤하님이 제시어를 고르고 있어요…"

**출제자 화면 위쪽:** 힌트 대신 "제시어: 고양이"가 보입니다.

**턴 종료 — 모두에게 5초 동안 표시**

```text
        ┌──────────────────────────────────┐
        │          정답은  「고양이」          │
        │                                  │
        │   민수 +115   현우 +90   윤하 +50   │
        │   지영  0                          │
        │                                  │
        │     다음 출제자: 민수 (5초 후)        │
        └──────────────────────────────────┘
```

- 맞힌 사람의 채팅 입력칸은 비활성화되고 "정답을 맞혔어요! 기다려 주세요"가 표시됩니다.
- 정답과 한 글자 차이면 본인에게만 "거의 맞았어요!"가 뜹니다.
- 남은 시간 10초부터 타이머가 빨간색으로 바뀝니다.

## 4. 결과 화면

```text
┌──────────────────────────────────────────────┐
│                  🏆 최종 순위                  │
│                                              │
│                  🐱 윤하                      │
│        🐶 민수   ┌──────┐                      │
│       ┌──────┐  │  1위  │   🐻 현우             │
│       │  2위  │  │ 320점 │  ┌──────┐           │
│       │ 285점 │  │       │  │  3위  │           │
│       │       │  │       │  │ 240점 │           │
│  ─────┴──────┴──┴──────┴──┴──────┴─────       │
│                                              │
│   4위  🐰 지영   150점                         │
│                                              │
│     [   다시 하기   ]      [   나가기   ]        │
└──────────────────────────────────────────────┘
```

- [다시 하기]를 누르면 같은 사람들과 대기실로 돌아갑니다. 점수는 0으로 초기화됩니다.

## 5. 모바일 (세로) — 게임 화면

```text
┌─────────────────────────┐
│ 1/3   ㄱ _ _      ⏱ 52 │
├─────────────────────────┤
│ 🐱120✏ 🐶95✔ 🐻80✔ 🐰40 │ ← 점수판을 한 줄로
├─────────────────────────┤
│                         │
│      (  캔 버 스  )       │
│      정사각형 비율         │
│                         │
├─────────────────────────┤
│ ●●●●●●●● ━━━ [⌫][↶][🗑] │ ← 출제자만
├─────────────────────────┤
│ 민수: 강아지?             │
│ ✅ 현우님 정답!           │
│ ( 정답 입력      ) [전송] │
└─────────────────────────┘
```

- 메인·대기실·결과 화면은 같은 내용을 세로로 쌓아서 보여 줍니다.
- 캔버스는 화면 너비에 맞추고 비율(정사각형)은 유지합니다. 좌표는 0~1로 저장해 화면 크기가 달라도 같은 그림이 보이게 합니다.

## 6. 화면 전환 흐름

```text
메인 ──(방 만들기/참가)──▶ 대기실 ──(게임 시작)──▶ 게임 ──(3라운드 끝)──▶ 결과
  ▲                         ▲                                          │
  └──────(나가기)────────────┴──────────────(다시 하기)──────────────────┘
```
