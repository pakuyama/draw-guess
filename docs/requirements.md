# 요구사항 — 무엇이 되어야 하나

## 1. 목표

친구·동료가 링크 하나로 모여 설치 없이 바로 즐기는 그림 맞히기 게임을 **8주 안에** 공개한다.

## 2. 사용자

- 친구끼리 가볍게 놀고 싶은 사람
- 수업·모임에서 분위기를 띄우고 싶은 진행자 (교사, 팀장)

## 3. 게임 규칙

1. 방장이 방을 만들고 방 코드(6자리) 또는 초대 링크를 공유한다.
2. 2~8명이 모이면 방장이 게임을 시작한다.
3. 매 턴 한 명이 출제자가 되어 제시어 3개 중 하나를 고른다. (10초 안에 안 고르면 자동 선택)
4. 출제자는 제한 시간(기본 80초) 동안 그림을 그린다. 글자·숫자 쓰기는 금지.
5. 나머지는 채팅으로 정답을 입력한다. 맞힌 정답은 다른 사람에게 보이지 않는다.
6. 시간이 지나면 힌트를 공개한다: 시작 시 글자 수, 40초 후 첫 글자 초성.
7. 모두 맞히거나 시간이 끝나면 턴 종료. 모두 한 번씩 출제하면 1라운드, 3라운드 후 최종 순위.

## 4. 점수

| 대상 | 점수 |
| --- | --- |
| 맞힌 사람 | 남은 시간 비례, 최대 100점 ~ 최소 20점 |
| 첫 정답 보너스 | +20점 |
| 출제자 | 맞힌 사람 1명당 25점 |

동점이면 첫 정답 횟수가 많은 사람이 위.

## 5. 기능 요구사항

### 필수 (MVP)

- [ ] R1. 닉네임만 입력하고 입장 (회원가입 없음)
- [ ] R2. 방 만들기, 방 코드·링크로 참가, 최대 8명 제한
- [ ] R3. 실시간 캔버스: 펜, 색 8가지, 굵기 3단계, 지우개, 전체 지우기, 되돌리기
- [ ] R4. 늦게 들어온 사람에게도 지금까지 그린 그림이 보임
- [ ] R5. 실시간 채팅과 정답 판정 (앞뒤 공백·띄어쓰기 무시)
- [ ] R6. 타이머, 힌트, 점수판, 최종 순위 화면
- [ ] R7. 제시어 사전 500개 이상 (쉬움/보통/어려움)
- [ ] R8. 접속이 끊겨도 30초 안에 돌아오면 자리·점수 유지
- [ ] R9. 방장이 나가면 다음 사람이 방장이 됨

### 나중에 (2차)

- 사용자 제시어 등록 (예: 수업 단원 단어)
- 방 설정: 라운드 수, 제한 시간, 난이도
- 공개 방 목록, 강퇴·신고, 금칙어 필터
- 그림 저장·하이라이트

## 6. 비기능 요구사항

- 그림이 다른 사람 화면에 나타나는 지연 200ms 이하 (같은 지역 기준)
- 한 방 8명이 끊김 없이 플레이
- PC 크롬·엣지, 모바일 크롬·사파리에서 동작
- 정답은 출제자 외 브라우저로 보내지 않음 (개발자 도구로 정답 보기 방지)

## 7. 성공 기준

- 한 게임(3라운드) 완주율 70% 이상
- [다시 하기] 선택률 50% 이상
- 출시 첫 달 플레이한 방 100개 이상
